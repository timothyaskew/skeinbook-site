Windows Installation

  1. Run SkeinBook Setup 0.1.0.exe
  2. Windows SmartScreen may warn you (we're not code-signed yet). Click "More info" → "Run anyway"
  3. Follow the installer — choose your install directory or accept the default
  4. Launch SkeinBook from the desktop shortcut or Start menu

macOS Installation

  1. Unzip the downloaded .zip file
  2. Drag SkeinBook.app to your Applications folder
  3. Double-click to open. macOS may block it since we're not notarized yet
  4. If blocked: right-click the app → Open → click Open in the dialog
  5. Alternatively: System Settings → Privacy & Security → scroll down → click "Open Anyway"

Linux Installation

  1. Make the AppImage executable: chmod +x SkeinBook-*.AppImage
  2. Run it: ./SkeinBook-*.AppImage
  3. Or right-click → Properties → Permissions → check "Allow executing"

Getting Started

  1. Import PDFs — Click the import button or drag files into the window
  2. Add your Claude API key (optional) — Settings → paste your key → AI will extract metadata automatically
  3. Connect Ravelry (optional) — Settings → Ravelry → authorize to sync your library
  4. Search and browse — use the filter bar to find any pattern by keyword, designer, weight, or tags

What's in v0.1.0-beta.1
