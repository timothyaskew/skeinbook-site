Installation Notes

  • Windows: Run the installer. SmartScreen may warn you — click "More info" → "Run anyway" (we're working on code signing).
  • Mac: Unzip, drag SkeinBook to Applications. If macOS blocks it, right-click the app → Open, then click Open in the dialog.
  • Updating: Just install the new version over the old one. Your pattern library is stored separately and won't be affected.
  • Your data location: Windows: %APPDATA%\skeinbook\ · Mac: ~/Library/Application Support/skeinbook/

What's in this build

  • Import PDFs individually or in bulk (1,400+ tested)
  • AI-powered metadata extraction (title, designer, yarn weight, gauge, needles)
  • Ravelry library sync with deduplication
  • Full-text search + filters (designer, weight, craft, tags)
  • Sort by title, date, designer, or yarn weight
  • Inline PDF viewer
  • Edit metadata, add tags, custom fields
  • Backup / restore (ZIP, CSV, JSON)
  • Right-click context menu on cards
  • Shift+click multi-select with undo-delete
